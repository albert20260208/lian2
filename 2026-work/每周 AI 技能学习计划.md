## 📋 每周例行任务

### 1. 回顾调研报告
- 📄 打开 `2026-work/热门 AI 技能习惯调研.md`
- 📖 重温已记录的热门技能和行为习惯
- ✏️ 更新过时信息或添加新发现

### 2. 探索新技能
- 🔍 **ClawHub**: https://clawhub.ai
  - 查看新发布的技能
  - 浏览 trending skills
- 🐙 **GitHub**: 搜索 `clawhub skill agent`
  - 按 stars 排序查看热门仓库
  - 关注更新频繁的项目

### 3. 分析与评估
- 💡 哪些技能适合当前工作流？
- 🔒 使用 **Skill Vetter** 审查感兴趣的技能
- 📝 记录评估结果：
  - 技能名称
  - 功能描述
  - 风险等级
  - 是否安装

### 4. 安装与测试（可选）
- ✅ 仅安装通过安全审查的技能
- 🧪 在测试环境中先试用
- 📖 记录使用体验

### 5. 文档更新
- 📄 更新 `2026-work/热门 AI 技能习惯调研.md`
- 📝 在 `TOOLS.md` 记录常用技能配置
- 🎯 在 `AGENTS.md` 添加新的行为习惯

## 🔧 Cron 配置（供参考）

如需自动提醒，可在 OpenClaw 中添加以下 cron 任务：

```json
{
  "name": "每周 AI 技能学习提醒",
  "schedule": {
    "kind": "cron",
    "expr": "0 10 * * 6",
    "tz": "Asia/Shanghai"
  },
  "payload": {
    "kind": "systemEvent",
    "text": "💓 每周 AI 技能学习时间\n\n📋 待办：\n1. 回顾 `2026-work/热门 AI 技能习惯调研.md`\n2. 浏览 ClawHub 查看新技能\n3. 搜索 GitHub 热门 AI skills\n4. 分析适合当前工作流的技能\n5. 用 Skill Vetter 审查感兴趣的技能\n6. 记录新发现\n\n🎯 目标：持续学习最新 AI 技能，保持工作流高效\n\n*每周六上午 10 点自动提醒*"
  },
  "enabled": true
}
```
