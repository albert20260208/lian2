## 2026-06-01: 配置文件保存方案

### 决策
将所有配置文件统一保存到 `~/.openclaw/configs/` 目录

### 背景
- 配置信息分散，容易丢失
- 需要安全保存 AccessKey 等敏感信息
- 需要方便备份和恢复

### 原因
1. **集中管理**: 所有配置在一个目录，便于查找
2. **安全性**: 可以设置统一的文件权限 (600/755)
3. **备份方便**: 只需备份一个目录
4. **恢复简单**: 提供备份和恢复脚本

### 备选方案
- **方案 A**: 分散保存（已放弃）
  - 缺点：难以管理，容易丢失
  
- **方案 B**: 加密云存储（作为补充）
  - 优点：更安全
  - 缺点：操作复杂
  
- **方案 C**: 统一目录（已采用）
  - 优点：平衡安全性和易用性

### 实施方案
1. 创建 `~/.openclaw/configs/` 目录
2. 移动所有配置文件到新目录
3. 创建备份和恢复脚本
4. 设置正确的文件权限
5. 创建配置文档

### 影响
- ✅ 配置文件集中管理
- ✅ 需要定期备份
- ✅ 敏感信息不提交到 Git
- ✅ 每 90 天轮换 AccessKey

- `~/.openclaw/configs/README.md`
- `~/.openclaw/configs/CONFIG-BACKUP-GUIDE.md`
- `lian2/docs/CONFIG-TEMPLATE.md`

## 2026-06-01: 阿里云 AccessKey 配置

### 决策
使用阿里云 AccessKey 配置 CLI，查询账单明细

### 背景
- 需要查询阿里云消费明细
- 当前只有 DashScope API Key（无法查询账单）
- 需要专门的 AccessKey 和 BSS 权限

### 原因
1. **功能需求**: DashScope Key 只能调用大模型 API
2. **权限分离**: 账单查询需要 BSS 权限
3. **安全性**: 使用最小权限原则

### 实施方案
1. 在 RAM 控制台创建 AccessKey
2. 添加 `AliyunBSSReadOnlyAccess` 权限
3. 配置本地 CLI
4. 测试查询功能
5. 备份配置信息

### 影响
- ✅ 可以查询账单明细
- ✅ 了解消费情况
- ✅ 便于成本控制

### 教训
- DashScope API Key (sk-xxx) ≠ 阿里云 AccessKey (LTAIxxx)
- 查询账单需要专门的 BSS 权限
- 配置文件需要安全备份
